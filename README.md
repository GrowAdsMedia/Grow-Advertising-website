# Grow Advertising Website

Static, responsive website ready for GitHub Pages.

## Files
- `index.html` — Home page
- `services.html` — Services and packages
- `portfolio.html` — Portfolio gallery
- `contact.html` — WhatsApp enquiry form
- `css/style.css` — Shared styling
- `js/script.js` — Mobile menu, animations, filters and WhatsApp form
- `assets/` — Logo, portfolio and presentation images

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `grow-advertising-website`.
2. Upload all files and folders from this directory to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide a temporary `github.io` URL.

## Custom domain
In **Settings → Pages → Custom domain**, add your domain after purchasing it from a domain registrar. Configure DNS using the values GitHub shows for your Pages setup, then enable HTTPS after DNS is verified.
